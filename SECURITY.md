# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private vulnerability reporting: open the repository's
[Security tab](https://github.com/bisforboman/stylebro/security) and choose **Report a vulnerability**. Don't open a
public issue for a vulnerability.

Include the StyleBro version, what an attacker can do, and the steps or a minimal project that shows it. You'll get an
answer in the report's thread.

## Supported versions

Fixes go into the latest release of StyleBro.Analyzers and StyleBro.Migrate on nuget.org
([releases](https://github.com/bisforboman/stylebro/releases)). Older versions don't get fixes; upgrade to the latest.
