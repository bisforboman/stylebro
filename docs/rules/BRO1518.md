# BRO1518: Closing braces should not be preceded by blank line

A closing brace directly follows the code above it. Replaces StyleCop **SA1508**.

## Example

### Before

```csharp
public class Inventory
{
    public int Count(int[] items)
    {
        return items.Length;

    }
}
```

### After

```csharp
public class Inventory
{
    public int Count(int[] items)
    {
        return items.Length;
    }
}
```

## Why

A blank line before `}` separates nothing from nothing, and makes the end of the block harder to see.

## How the fix works

The blank lines between the last line of code (or comment) and the `}` are removed.

This rule replaces the SDK's IDE2002, which writes merge conflict markers in multi-targeted projects under
`dotnet format` (see [decisions](../decisions.md)).

## Not reported

- **Below a `//` comment** when [BRO1506](BRO1506.md) is on, and **in an empty block** (`{`, blank lines, `}`) when
  [BRO1503](BRO1503.md) is on: those rules remove the same lines.

## Compared with StyleCop

Same positions and output, apart from the places left to the rules above.
