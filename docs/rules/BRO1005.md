# BRO1005: Documentation lines should begin with single space

Each `///` documentation line has exactly one space before its text. Replaces StyleCop **SA1004**.

## Example

### Before

```csharp
/// <summary>
///Creates an order.
///   Orders start empty.
/// </summary>
public class Order
{
}
```

### After

```csharp
/// <summary>
/// Creates an order.
/// Orders start empty.
/// </summary>
public class Order
{
}
```

## Why

Documentation reads like prose; a line without the space or with extra indentation looks like a typo, and lines line up only when they all start the same way.

## How the fix works

The whitespace after `///` becomes one space. Lines with nothing after `///` are left alone, and so are lines inside `<code>`, where indentation is part of the example.

## Compared with StyleCop

Same positions and the same fixed output as StyleCop.
