# BRO1106: Use string.Empty for empty strings

`""` should be written as `string.Empty`. Replaces StyleCop **SA1122**.

## Example

### Before

```csharp
public class Person
{
    public string Name { get; set; } = "";

    public bool HasName() => Name != "";
}
```

### After

```csharp
public class Person
{
    public string Name { get; set; } = string.Empty;

    public bool HasName() => Name != string.Empty;
}
```

## Why

`string.Empty` states the intent, while `""` can look like a string that is missing its text, or one where a space was
lost. One way of writing it also makes empty strings easy to search for.

## Not reported

`string.Empty` is not a compile-time constant, so wherever C# requires a constant the literal stays:

- `const` fields and locals, including a `""` inside a longer constant expression (`const string X = "" + "a"`)
- attribute arguments: `[Obsolete("")]`
- parameter default values: `void M(string s = "")`
- `case ""` labels and patterns: `s is ""`, `"" => ...` in a switch expression (the arm's result, `_ => ""`, is
  replaced)

Interpolated (`$""`) and UTF-8 (`""u8`) literals are different kinds of literal and aren't reported either.
