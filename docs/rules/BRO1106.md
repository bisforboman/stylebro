# BRO1106: Use string.Empty for empty strings

Replaces StyleCop **SA1122**, with the same results.

Reports `""` and `@""`, and replaces them with `string.Empty`.

## Not reported

`string.Empty` is not a compile-time constant, so wherever C# requires a constant the literal stays, like StyleCop:

- `const` fields and locals, including a `""` inside a longer constant expression (`const string X = "" + "a"`)
- attribute arguments: `[Obsolete("")]`
- parameter default values: `void M(string s = "")`
- `case ""` labels and patterns: `s is ""`, `"" => ...` in a switch expression (the arm's result, `_ => ""`, is replaced)

Interpolated (`$""`) and UTF-8 (`""u8`) literals are different kinds of literal and aren't reported either.
