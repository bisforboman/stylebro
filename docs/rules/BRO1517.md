# BRO1517: Code should not contain multiple blank lines in a row

Two or more blank lines in a row become one. Replaces StyleCop **SA1507**.

## Example

### Before

```csharp
public class Report
{
    public int Total(int a, int b)
    {
        var sum = a + b;


        return sum;
    }
}
```

### After

```csharp
public class Report
{
    public int Total(int a, int b)
    {
        var sum = a + b;

        return sum;
    }
}
```

## Why

One blank line separates; more add scrolling without saying anything more.

## How the fix works

The first blank line stays, the others are removed. Blank lines inside strings and in disabled `#if` code aren't
touched.

This rule replaces the SDK's IDE2000, which writes merge conflict markers in multi-targeted projects under
`dotnet format` and also counts blank lines at the start of a file and before `}` (see [decisions](../decisions.md)).

## Not reported

- **At the start or end of the file**: the end is [BRO1507](BRO1507.md)'s.
- **Right after `{`**, **right before `}`** and **below a `//` comment** when [BRO1503](BRO1503.md),
  [BRO1518](BRO1518.md) or [BRO1506](BRO1506.md) is on: those rules remove all of them there.

## Compared with StyleCop

Same positions and output, apart from the places left to the rules above.
