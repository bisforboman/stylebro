# BRO1102: Each attribute should be in its own brackets

Replaces StyleCop **SA1133**.

Reports attribute lists with more than one attribute, such as `[Obsolete, DebuggerStepThrough]`.

## Code fix

Splits the list so each attribute has its own brackets. A target is repeated on every part:
`[assembly: A, B]` becomes `[assembly: A]` and `[assembly: B]`.

- A list on its own line becomes one line per attribute, at the same indentation:

  ```csharp
  [Obsolete("Use Apply")]
  [DebuggerStepThrough]
  public void Reset() { }
  ```

- A list that shares its line with code stays on that line: `[Obsolete, DebuggerStepThrough] void M()` becomes
  `[Obsolete] [DebuggerStepThrough] void M()`.

Arguments are kept exactly as written.

## Not reported

- **Attributes on parameters and type parameters** (`void M([A, B] int x)`), like StyleCop.
- **Lists with a comment or directive between the attributes** (`[A, /* why */ B]`). Splitting would have to move or
  drop the comment; StyleCop's fix drops it.
