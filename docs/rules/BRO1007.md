# BRO1007: Partial elements should declare an access modifier

Every part of a partial type says its accessibility. Replaces StyleCop **SA1205**.

## Example

### Before

```csharp
public partial class Order
{
}

partial class Order
{
}
```

### After

```csharp
public partial class Order
{
}

public partial class Order
{
}
```

## Why

A part without a modifier doesn't tell the reader the type's accessibility; it has to be looked up in another file.

## How the fix works

The fix writes the type's accessibility as another part declares it, or the default when no part does. It goes before
the other modifiers (after attributes).

## Not reported

- **`file` types**, and types nested in interfaces.

## Compared with StyleCop

Same positions and output.
