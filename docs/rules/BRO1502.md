# BRO1502: Chained blocks should not be preceded by a blank line

Replaces StyleCop **SA1510**, with the same results.

Reports `else`, `catch` and `finally` with a blank line directly above them:

```csharp
if (ready)
{
    Start();
}

else
{
    Wait();
}
```

This also applies when the `if` has no braces.

## Code fix

Removes the blank lines directly above the keyword.

## Not reported

- **A comment or directive directly above the keyword** (for example a comment explaining the `else` branch).
- **The `while` of a `do … while` loop**, like StyleCop.
