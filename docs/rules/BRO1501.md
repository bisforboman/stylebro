# BRO1501: Opening braces should not be preceded by a blank line

Replaces StyleCop **SA1509**, with the same results.

Reports an opening brace on its own line with a blank line directly above it:

```csharp
public void Save()

{
}
```

This covers every kind of opening brace: types, members, statements, initializers and `case` blocks.

## Code fix

Removes the blank lines directly above the brace. A comment directly above the brace is kept; blank lines above
that comment are left alone.

## Not reported

- **A brace whose previous token is a `}`**, such as a block following another block, even with a comment in
  between. StyleCop makes the same exception. A standalone block after an ordinary statement is reported:

  ```csharp
  var path = GetPath();

  {            // BRO1501, like SA1509
      Use(path);
  }

  {            // not reported: follows a '}'
  }
  ```

- **A comment or directive directly above the brace.**
- **Braces inside strings**, such as `{x}` in a multi-line interpolated string. Only whitespace outside code is
  checked, never string contents.
