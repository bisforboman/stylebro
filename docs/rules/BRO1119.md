# BRO1119: Parameter should follow comma

No blank line between a comma and the next parameter or argument. Replaces StyleCop **SA1115**.

## Example

### Before

```csharp
public class Mailer
{
    public void Send(
        string to,

        string subject)
    {
    }
}
```

### After

```csharp
public class Mailer
{
    public void Send(
        string to,
        string subject)
    {
    }
}
```

## Why

Blank lines inside a parameter list make it look like two lists.

## How the fix works

The blank lines are removed. The same lists as [BRO1118](BRO1118.md) are checked.

## Not reported

- **A comment between the comma and the item.**

## Compared with StyleCop

Same positions as StyleCop. StyleCop has no fix for SA1115.
