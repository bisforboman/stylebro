# Decisions

Design questions that came up while building StyleBro, the choices considered, and what was decided: one file per
decision in [decisions/](decisions/), named `<yyyy-mm-dd>-<slug>.md`, so the folder lists them by date and parallel pull
requests never edit the same file.

A new decision: `pwsh scripts/New-Decision.ps1 -Title "<the question in a few words>"` writes the file with the
Question, Choices and Decision headings and prints its path.
