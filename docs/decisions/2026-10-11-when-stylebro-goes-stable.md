# When StyleBro goes stable (2026-10-11)

## Question

What has to be true before StyleBro ships 1.0?

## Choices

1. **Two clean trials in a row**: first-run trials on new kinds of repository with no high-severity bugs.
2. Two clean trials plus a few external users.
3. No fixed bar; release 1.0 when it feels ready.

## Decision

**Choice 1** (owner, 2026-10-11). External users aren't required. The tally is kept in the backlog item "Two clean
trials before 1.0" (trial 8 was in progress when this was decided); `docs/versioning.md` states the bar.
