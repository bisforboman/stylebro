### Changed

- **The docs describe StyleBro on its own.** Rule pages no longer compare each rule with StyleCop; each still names the
  StyleCop rules it replaces. The "StyleBro vs StyleCop" and "Differences from StyleCop" pages are gone. The StyleCop
  rule mapping, the StyleCop rules StyleBro doesn't cover, and the migration guide stay.

### Fixed

- **`bro migrate`** no longer treats [BRO1617](https://bisforboman.github.io/stylebro/rules/BRO1617/) as the replacement
  for SA1653: StyleCop 1.3's SA1653 is a different rule (one `<summary>` per partial type), so a repository on a 1.3 beta
  doesn't get BRO1617 turned on for it.
