### Fixed

- StyleBro no longer reports anything in files a source generator writes. A generator doesn't have to name its files
  `.g.cs` or start them with an `<auto-generated>` header, and then every rule reported there, in a file nobody can
  edit and `dotnet format` can neither fix nor baseline (a build with warnings as errors stayed broken).
- **BRO1514-BRO1516** put braces on every clause of an `if`/`else` chain in one run when braces on one clause (a
  multi-line `else if`) make the others inconsistent; `dotnet format` needed a second run before.
- **BRO1303/BRO1306** leave private static fields alone when a `dotnet_naming_rule` for them asks for a style StyleBro
  doesn't write, such as an `s_` prefix. Before, `private static readonly CultureInfo _culture` became `Culture`,
  against the team's own rule.
- **BRO1306** renames the public fields of a private nested class even when the name appears as a word in a string
  somewhere else: code outside the class can't see them. Only a string that names a member for reflection keeps them,
  as for private fields.
- **BRO1149** puts the `&&` of a merged condition at the end of the line when **BRO1520** is off, where the outer
  condition ended, instead of following an operator placement setting nothing enforces.
- **BRO1303/BRO1306** no longer rename a field to the name of its own class (`class Text` with a field `text`),
  which doesn't compile.
