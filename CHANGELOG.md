# Changelog

The changelog is [GitHub Releases](https://github.com/bisforboman/stylebro/releases): each release's notes say what
changed. What the version numbers mean: [docs/versioning.md](docs/versioning.md).

One line per release so far (all prereleases; before 1.0 anything may change):

- **0.5.0-alpha.1** (2026-10-10): fixes for renames inside `#if` code and `--diff` previews; findings kept on purpose
  say why.
- **0.4.0-alpha.1** (2026-10-10): BRO1008 replaces IDE0065 (builds broke after `init`), no renames through `nameof`,
  SonarQube support in `stylebro-migrate`; 129 rules.
- **0.3.0-alpha.1** (2026-10-09): BRO1410 and 11 settings for teams that prefer otherwise; 125 rules.
- **0.2.0-alpha.1** (2026-10-06): 53 new rules, `stylebro-migrate format` for multi-targeted repositories, the PR
  pipeline (parity, real-world runs, mutation testing).
- **0.1.0-alpha.8** (2026-10-02): baseline support and a BRO1117 crash fix; 71 rules.
- **0.1.0-alpha.7** (2026-10-02): 71 rules.
- **0.1.0-alpha.6** (2026-10-01): 54 rules; the first prerelease published without an approval step.
- **0.1.0-alpha.5** (2026-10-01): the `stylebro-migrate` tool (StyleBro.Migrate).
- **0.1.0-alpha.4** (2026-10-01): 43 rules.
- **0.1.0-alpha.3** (2026-09-30): 18 rules.
- **0.1.0-alpha.2** (2026-09-30): 11 rules, rule pages with tested examples, Fix All in multi-targeted projects.
- **0.1.0-alpha.1** (2026-09-30): the first release, BRO1001 member ordering.
